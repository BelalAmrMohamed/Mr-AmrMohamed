# Project Context Map 

## Description
`PROJECT_STRUCTURE.md`: A generated file that provides a visual representation of the project's directory structure. It is intended to help developers and contributors understand the organization of the project and locate files more easily. The map is generated by traversing the project directory and listing all files and folders, while respecting .gitignore rules and other specified ignore settings.

The map is useful for quickly identifying the layout of the project, understanding the relationships between different components, and navigating the codebase. It can also serve as a reference for new contributors to get acquainted with the project's structure.

Note: Some of the contents listed in this structure may not appear in the output `.zip` file given to AI Chats, like `public/assets`, which is intentionally `export-ignore` in the `.gitattributes`, because it contains big video, pdf, and image files, but it exists in the actual repo, you can still see its contents in here.
